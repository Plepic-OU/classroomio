# Day 4, workshop 1 — observing your own Claude usage

## Goal

Run the `/insights` skill against your own session history, read the report it generates, and use it as a mirror — pick one thing you learned and one suggestion you'd act on. Share both with the class.

## What you'll learn

- What `/insights` shows you about your own Claude usage.
- That the most useful continuous-improvement loop is the one you run on *yourself*, not on the agent.

## Steps

1. **Run `/insights` in Claude Code** and let it generate the report.

2. **Read the report.** Pick one session you remember well and check whether the report's view of it matches your own.

3. **Pick your two answers.** You're going to post both to Discord, so think before you type:
   1. *What did you learn about your Claude usage?* If anything — "nothing surprising" is a valid answer if you say why.
   2. *Which suggestion from Claude to improve makes sense to you?* If any — same rule, "none of them" is valid if you explain.

4. **Post to the class Discord channel.** One message, both answers.

## Optional / advanced

- **Build a personal-improvement skill.** Write a small skill that reads the current session's messages and proposes concrete changes you could make to reduce wasted turns. Run it at the end of a session for a week.
- **Compare across projects.** If you use Claude on more than one environment, run `/insights` per environment and compare the difference.
